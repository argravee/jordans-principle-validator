# Jordan’s Principle Document Validator

This is an NLP-assisted, rule-based system for pre-submission validation of completed Jordan’s Principle application documents.

## Overview
This project aims to reduce preventable administrative delays by identifying missing, inconsistent, or unclear information in application packages prior to submission.

The system is advisory only and keeps humans fully in the loop.
